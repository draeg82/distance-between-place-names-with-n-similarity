# DistNSimilarity

Find pairs of places whose ASCII names differ by exactly *n* characters, and report the great-circle distance between each pair as a CSV. Inputs are GeoNames places dumps (`cities1000.txt`, `cities5000.txt`, `cities15000.txt`).
